📊 Métricas de Evaluación para Modelos de ClasificaciónEsta guía explica de forma intuitiva las cuatro métricas principales utilizadas para evaluar el rendimiento de los modelos de clasificación en Machine Learning: Accuracy, Precision, Recall y F1-Score.🧠 Concepto Previo: La Matriz de ConfusiónAntes de pasar a las métricas, es fundamental entender los cuatro resultados posibles al evaluar una predicción, los cuales forman la Matriz de Confusión:Verdadero Positivo (TP): El modelo predijo que SÍ y acertó.Verdadero Negativo (TN): El modelo predijo que NO y acertó.Falso Positivo (FP): El modelo predijo que SÍ, pero se equivocó (Falsa alarma).Falso Negativo (FN): El modelo predijo que NO, pero se equivocó (Se le escapó un caso real).1. Accuracy (Exactitud)Responde a la pregunta: De todas las predicciones que hizo el modelo, ¿qué porcentaje fue correcto?$$Accuracy = \frac{TP + TN}{TP + TN + FP + FN}$$⚠️ El problema: Es engañosa si los datos están desbalanceados. Si tienes 99 casos negativos y 1 positivo, un modelo inútil que siempre prediga "negativo" tendrá un Accuracy del 99%, pero fallará en el único caso que importaba.💡 Cuándo usarla: Cuando las clases están balanceadas y tanto los Falsos Positivos como los Falsos Negativos tienen el mismo costo o impacto.2. Precision (Precisión)Responde a: De todos los casos que el modelo clasificó como "Positivos", ¿cuántos lo eran realmente?$$Precision = \frac{TP}{TP + FP}$$🎯 El enfoque: Penaliza los Falsos Positivos. Una alta precisión significa que cuando el modelo dice que algo es positivo, es muy confiable.💡 Cuándo usarla: Cuando el costo de una falsa alarma (Falso Positivo) es muy alto.Ejemplo: En un filtro de Spam. Prefieres que un correo Spam llegue a tu bandeja (Falso Negativo) a que un correo importante de trabajo sea clasificado como Spam y se elimine (Falso Positivo).3. Recall (Sensibilidad o Exhaustividad)Responde a: De todos los casos positivos reales, ¿cuántos logró detectar el modelo?$$Recall = \frac{TP}{TP + FN}$$🔍 El enfoque: Penaliza los Falsos Negativos. Un alto recall significa que al modelo rara vez se le escapa un caso positivo.💡 Cuándo usarla: Cuando el costo de ignorar un caso real es catastrófico.Ejemplo: En la detección de enfermedades graves. Un Falso Positivo solo implica hacer más análisis médicos, pero un Falso Negativo significa que un paciente enfermo no recibe tratamiento.4. F1-ScoreEn la práctica, suele haber un balance (trade-off) entre Precision y Recall. Si ajustas tu modelo para atrapar todo, aumentan las falsas alarmas. Si lo haces muy estricto, se escapan casos reales.El F1-Score es la media armónica entre Precision y Recall. Responde a: ¿Qué tan bien equilibrado está el modelo entre no dar falsas alarmas y no dejar escapar casos reales?$$F1 = 2 \times \frac{Precision \times Recall}{Precision + Recall}$$⚖️ El enfoque: Se usa la media armónica porque esta castiga severamente los valores extremos. Si un modelo tiene un Recall perfecto pero una Precision pésima, el F1-Score será bajo, reflejando que el modelo está fallando.💡 Cuándo usarla: Cuando tienes conjuntos de datos desbalanceados y necesitas una única métrica para comparar qué modelo tiene el mejor rendimiento general.
